# DEMO_CHEATSHEET — 呷安心 現場展示小抄

> 以 2026-10-05 production read-only 回歸的 PASS 案例為準。延遲是實測（含 OpenAI），現場網路可能 ±30%。展示前先按「開始新問題」。每個案例失敗時，先用「備援」。

## CORE（8 個，建議順序）

### D1｜官方產品查證
- **輸入／素材**：文字：`漁人健康魚油軟膠囊有沒有通過健康食品認證？`
- **預期第一張卡**：🟢 產品資訊：官方確認登記；按鈕「查看產品資訊／查看完整成分／查看資料來源」
- **要按的按鈕**：「查看完整成分」→ 標題「保健功效相關成分（3 項）」，只列官方成分名稱
- **對評審說**：「答案先講結論：這是官方有登記的產品，細節要看再按。」
- **預期延遲**：約 8.4s
- **緊急備援**：B1：高鈣脫脂奶粉（5.3s），或 #2 直接輸入字號 `衛部健食規字第000048號`（6.0s）

### D2｜圖片＋短期記憶
- **輸入／素材**：照片：漁人健康魚油軟膠囊 包裝正面（品名＋字號 衛部健食規字第000048號）→ 立刻傳文字 `它有哪些成分？`
- **預期第一張卡**：先出產品資訊卡，再出「成分資訊」卡（它＝剛剛那個產品）
- **要按的按鈕**：「查看完整成分」
- **對評審說**：「我先查完圖片，再回答你接著問的問題，『它』會對到剛剛確認的產品。」
- **預期延遲**：約 15.0s
- **緊急備援**：#19 純文字：先問核准功效再問 `它有哪些成分？`（5.8s）

### D3｜多張照片自動融合
- **輸入／素材**：一次選 3 張照片（正面品名／背面成分／字號）直接傳送，不按任何按鈕
- **預期第一張卡**：只出 1 張結果卡：產品資訊（官方確認），沒有中間「找不到」
- **要按的按鈕**：「查看產品資訊」
- **對評審說**：「三張是同一產品才會融合；字號或品名衝突會先請你確認，不會硬選。」
- **預期延遲**：約 17.1s
- **緊急備援**：#13 明確模式：「開始新問題」→「多照片辨識」→ 2 張 →「開始分析」（12.8s）

### D4｜包裝觀察
- **輸入／素材**：照片：品名＋核准宣稱原句 → 按「檢視包裝宣稱」
- **預期第一張卡**：產品資訊卡（有「檢視包裝宣稱」）；按下後立刻出「包裝上辨識到的內容」
- **要按的按鈕**：「檢視包裝宣稱」（<1 秒，不查任何外部資料）
- **對評審說**：「這一步只整理照片上的字，明講尚未與官方資料比對，不會冒充官方結論。」
- **預期延遲**：約 12.8s + 即時
- **緊急備援**：#16：傳一張未確認產品的飲品照片，再問 `剛剛那張照片上寫了什麼？`（4.5s）

### D5｜醫療宣稱安全
- **輸入／素材**：文字：`漁人健康魚油軟膠囊的廣告說可以治療糖尿病`
- **預期第一張卡**：🔴 風險判斷（HIGH，針對這句宣稱）；產品本身仍是官方確認
- **要按的按鈕**：「查看完整分析」（約 3 秒）
- **對評審說**：「產品是真的，但廣告說治療疾病是違規說法——真偽和宣稱風險分開判斷。」
- **預期延遲**：約 8.7s
- **緊急備援**：#10b 圖片版：品名＋『保證根治糖尿病』（14.9s）

### D6｜知識圖譜交互作用＋證據
- **輸入／素材**：文字：`鋅和銅可以一起吃嗎？`
- **預期第一張卡**：交互作用結果：有資料庫紀錄、但適用條件尚未評估（不說「可以／不可以」）
- **要按的按鈕**：「為什麼？」→「查看證據」
- **對評審說**：「結論只來自知識圖譜與官方證據，而且明說尚未評估你的劑量。」
- **預期延遲**：約 5.3s
- **緊急備援**：#21：`鈣和Levothyroxine可以一起吃嗎？`（5.6s）

### D7｜證據衝突
- **輸入／素材**：文字：`魚油和Warfarin有沒有交互作用？`
- **預期第一張卡**：「目前證據不一致」，不下肯定結論
- **要按的按鈕**：「查看證據」→ 逐筆列出證據方向
- **對評審說**：「證據互相矛盾時，系統不選邊，直接告訴你衝突。」
- **預期延遲**：約 5.6s
- **緊急備援**：#22b：`鈣和鐵可以一起吃嗎？`（待審證據，5.3s）

### D8｜網址輸入（官方頁）
- **輸入／素材**：貼上：`https://consumer.fda.gov.tw//Food/InfoHealthFoodDetail.aspx?nodeID=162&id=1492`
- **預期第一張卡**：產品資訊（官方網域頁不會被當成廣告宣稱）
- **要按的按鈕**：「查看資料來源」（可點開官方來源）
- **對評審說**：「貼官方頁會被認成官方來源；貼廣告頁只會當成『對方宣稱』再回官方資料查證。」
- **預期延遲**：約 15.9s
- **緊急備援**：B2：高鈣脫脂奶粉 的官方頁（21.9s），或 D1

## BACKUP（有空再展示／替換用）

- **typo 候選確認**：`漁人健康錯油軟膠囊有哪些成分？` → 候選卡「選擇：漁人健康魚油軟膠囊」→ 點選後直接出成分（約 9.0s + 2.1s）
- **含特定成分**：`漁人健康魚油軟膠囊有含二十碳五烯酸嗎？` → 成分資訊：官方列有該成分（約 6.3s）
- **獨立營養素**：`鋅有什麼功能？` → 成分資訊（不綁定產品）（約 14.5s）
- **重複成分（兩個產品）**：兩個真實產品＋共同營養素（見 DEMO_REGRESSION #23） → 交互作用結果：重複成分提醒，未評估攝取量（約 9.5s）
- **查無產品**：`虛構測試晶亮膠囊乙丙有哪些成分？` → 需要補充：「查不到不代表是假貨」（約 20.3s（偏慢，不當 CORE））
- **交互作用 coverage gap**：`鋅和薑黃可以一起吃嗎？` → 「結構化交互作用資料尚未收錄…」，不要求重打、不下結論（約 28.6s（偏慢））
- **語音輸入**：語音：`請問高鈣脫脂奶粉有哪些成分`（合成語音實測） → 成分資訊（轉錄簡體字會自動轉繁體）；若聽成同音字會出候選卡，點選即可（約 9.8s）
- **真的無法辨識的詞**：`鋅和啊咕嚕嗚拉可以一起吃嗎？` → 需要補充：請確認寫法（不上網猜）（約 7.9s）

## 不要現場展示

- **語音當 CORE**：ASR 可能聽成同音字（會出候選確認卡，不會誤確認）。要展示請用 BACKUP 的語音案例，並預期可能多一步「選擇」。
